# /leaderboard 视觉分析

**wave**: dashboard | **viewport**: 1440 | **截图数**: 1
**截图清单**：
- `screenshots/dashboard/leaderboard-default-1440.png` — 排行榜

**a11y 树要点**：
- 1 H1: "排行榜"
- 多组 tablist (时间/场景/榜单类型)
- 1 button "去训练大厅" (重复 2 次)
- 0 console error
- sidebar "排行榜" active 态正确

---

## P0（必须修）

### P0-1：副标题文案错别字 / 语义不通
- **位置**：H1 下方副标题
- **原文**：「按号分级练习的排名，疑是当期排行练习」
- **疑点**：
  - "按号"应是"按号"或"按次"（错别字）
  - "疑是"→"疑似"或"是"（语义错位）
  - 整句读不通
- **影响**：
  - 用户无法理解榜单逻辑
  - 显得产品未校对
- **修复方向**：
  - 重写为「按练习分数排名的榜单。疑是当期排行练习，请见当期排行练习约定。」
  - 实际建议：「按可评估训练均分排名。当期榜单为本周已完成的训练。」

---

## P1（1 周内）

### P1-1：当前用户卡位置"灰色背景"，与主榜视觉权重倒挂
- **位置**："我的排名 综合分榜" 卡片
- **现象**：当前用户卡用淡蓝背景，**理应是视觉焦点**（用户首先想看自己），但排在大空状态下方
- **影响**：用户先看到"暂未加入我的附近排名"再看到自己，路径反
- **修复方向**：当前用户卡上移 + 突出显示（如用 primary border）

### P1-2：3 组 tab 视觉权重等同
- **位置**：时间 tab / 场景 tab / 榜单 tab
- **现象**：3 组 tab 都是浅灰背景，无强层级
- **影响**：用户不知道"先选时间还是先选场景"
- **修复方向**：第一组 tab（时间）用 segmented control 更显眼

### P1-3：底部说明字号过小
- **位置**："若多次顶级组别不是不服不平不稳..." 文字
- **现象**：小灰字 + 难以阅读
- **修复方向**：作为 collapsible "积分规则" 折叠，展开后正常字号

## P2（可优化）

### P2-1："去训练大厅 →" 出现 2 次
- 同一页 2 个相同 CTA，用户疑惑哪个是主路径
- 修复：保留 1 个，把另一个改为"了解训练"

### P2-2：0 次练习 / 均分 0 状态
- "我的排名" 卡片显示 0 数据
- 可加"开始首场训练 →" 替换为 CTA

### P2-3：场景 chip "PPT 演练" 与 sales-trainer 主页面名称一致
- ✅ 一致

## P3（可选）

### P3-1：无 mock/demo 数据
- 新用户看不到排行榜长什么样
- 修复：加"查看示例排行"折叠区

### P3-2：无匿名化选项
- 排行榜是实名 → 员工压力
- 修复：加"仅显示部门" / "匿名" 开关

## 视觉层级评估

- **视线流**：H1 → 描述 → 时间 tab → 场景 tab → 榜单 tab → 当前用户 → 附加 → 空状态 → 规则
- **CTA 强度**："去训练大厅"是唯一 CTA，但出现 2 次
- **建议**：合并 CTA + 把"附加排名"区域改为"已加入我的附近" + 显示真实数据

## 一致性

- ✅ 与 / 同样的 sidebar 与字体
- ❌ 文案错别字是项目级问题（其他页暂未发现同样错误，但需全站文案校对）

---

## 总结

/leaderboard 是项目**空状态设计最好的页面之一**：2 个空状态都用引导性 CTA 替代"暂无数据"。**主要问题是文案错别字**（P0-1）和当前用户卡位置不当（P1-1）。
