# /admin 视觉分析

**wave**: admin | **viewport**: 1440 | **截图数**: 1
**截图清单**：
- `screenshots/admin/admin-default-1440.png` — 管理控制台

**a11y 树要点**：
- 1 H1: "管理控制台"
- 4 metric cards
- 3 "待你真实统计" 区块 + 数据采集卡
- 0 console error

---

## ⚠️ 重大发现：项目存在两套 sidebar

| 区域 | 路径 | sidebar 菜单 |
|---|---|---|
| dashboard 区 | /, /training, /history, /profile 等 | 首页 / 训练模式 / 销售训练 / 排行榜 / 历史记录 + 系统分组 |
| **admin 区** | /admin, /admin/users 等 | **概览 / 管理员 / 内容知识库 / 智能体与角色 / 营销与训练 / 数据分析 / 业务规则 / 学习内容管理 / 评分标准 / 系统设置** |

**问题**：
- 用户从 dashboard 跳到 admin 后，**整个左栏菜单全变**
- 没有任何视觉提示"我现在在 admin 区"
- 没有"返回学员区"快捷入口
- 头像 / 用户信息显示位置也变了

**影响**（P0-1）：
- 信息架构混乱
- 用户在 admin 操作完，找不到回 dashboard 的路
- 看起来像两个产品粘在一起

**修复方向**：
- 方案 A：合并 sidebar，admin 项加次级菜单
- 方案 B：保留两套但加"返回学员区"按钮 + 区域徽章（如顶部条 "📋 学员区 | 🔧 管理区" 切换器）

---

## P0（必须修）

### P0-1：两套 sidebar，跨区切换体验差（详见上）

### P0-2：管理员空状态"待你真实统计"3 个区块含义不清
- **位置**：3 个并排的浅色卡
- **原文**：每块标题 "待你真实统计"
- **现象**：用户不知道这是在等什么数据 / 等什么操作
- **影响**：管理员不知道第一步该做什么
- **修复方向**：
  - 加"这是什么？"展开说明
  - 或改为"配置 X / 配置 Y / 配置 Z"动作化

---

## P1（1 周内）

### P1-1：admin sidebar 10+ 项无分组
- 所有菜单项平铺，没用分隔线 / section 标题 / 折叠
- 修复：参照 dashboard 模式加 section header "运营 / 内容 / 系统"

### P1-2：4 个 metric 全 0.0%
- 与 dashboard 同样的空态问题
- 0.0% 用大紫字反而放大"空"的视觉
- 修复：空态用浅灰 + "暂无数据，等用户产生后自动累积"

### P1-3：副标题文案
- "本控台为管理员提供..." 文字密集
- 修复：缩短为一行"管理员工作台"

## P2（可优化）

### P2-1：admin 头像位置与 dashboard 不一致
- dashboard：底部带折叠按钮
- admin：底部 1 行紧凑
- 修复：统一

### P2-2：缺少 admin 顶栏
- 缺面包屑、缺搜索、缺通知
- 修复：参考 dashboard 模式

### P2-3："待你真实统计"3 卡与 4 metric 视觉权重等同
- 主路径是配置/统计，不是"查看" → 应有主 CTA

## P3（可选）

### P3-1：admin 缺"角色权限"自检
- 不知道当前 dev 登录是什么 admin 角色

### P3-2：admin 缺"审计日志"快捷入口
- admin 操作应该可追溯

## 设计 token 实测

| 维度 | 实测值 | token | 偏差 |
|---|---|---|---|
| 主背景 | #FAFAF9 渐变 | ✅ | 0 |
| 4 metric 数字"0.0%" | 紫 | ✅ | 0 |
| "待你真实统计" 卡背景 | 浅紫 | ⚠️ 未确认 token | 用法轻偏 |
| 圆角 | 16/24 | ✅ | 0 |
| 阴影 | 浮起 | ✅ | 0 |

**结论**：admin 与 dashboard 共享同一 token 体系，**但 layout 组件是分叉的**。

---

## 视觉层级评估

- **视线流**：H1 → 描述 → 4 metric → 3 配置卡 → 数据采集
- **CTA 强度**：右上"管理员入口"+ 3 个"进入统计"+ 数据采集入口 — 多个并列
- 修复：3 配置卡应改为大按钮 + 详细说明

## 一致性（与 dashboard 对比）

- ❌ **两套 sidebar**（P0）
- ❌ admin 头像位置不同
- ✅ 圆角 / 字体 / 配色延续
- ✅ 卡片样式统一

---

## 总结

/admin 是项目**最暴露 IA 问题的入口**：
- 跨区切换无引导 → 整个 admin 体验被打散
- 50+ admin 页面继承同样的"分裂 sidebar"，是放大版的同源问题
- **修复两套 sidebar 应是 top-1 优先级**

至此 sampling 完成（12 页覆盖 public / dashboard / admin 各模式），**下一轮切到聚合阶段**。
