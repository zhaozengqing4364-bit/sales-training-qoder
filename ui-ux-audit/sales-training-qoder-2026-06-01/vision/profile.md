# /profile 视觉分析

**wave**: dashboard | **viewport**: 1440 | **截图数**: 1

**a11y 树要点**：

- 0 console error

---

## P0（必须修）
- 无

## P1（1 周内）

### P1-1：评分 79 分无满分 / 等级解释
- **位置**：平均评分 metric card
- **现象**：显示"79 分"，无满分（100？120？）、无等级（优秀/良好）、无趋势箭头
- **影响**：用户不知道 79 是好是坏
- **修复方向**：
  - 数字下加"满分 100"或"+"号表示正向
  - 加 ⓘ tooltip 解释评分体系
  - 颜色：≥80 绿 / 60-79 黄 / <60 红

### P1-2：0 次练习 metric 与其他 metric 视觉权重等同
- **位置**："本周练习 0 次"
- **现象**：本周 0 与历史 25 平均分 79 同等视觉权重
- **影响**：用户看不出"本周 vs 累计"对比
- **修复方向**：0 metric 弱化（灰字 + 小尺寸）

### P1-3：修改密码 link 流向有缺陷的流程
- **位置**：系统设置 → 修改密码
- **现象**：点击 → /forgot-password（前面审计发现密码不一致无 inline 错误）
- **影响**：用户改密码体验差
- **修复方向**：
  - 改密码应用专门的 /change-password 流程（输入旧 + 新 + 确认）
  - 而不是走 /forgot-password 邮件重置

## P2（可优化）

- 纯文字 button 在 user card 右上角，与整体 lucide 图标风格不一致

### P2-2：语音播放速度 1.0x 调节器
- 看起来是 dropdown/select，但点击范围小
- 修复：增大点击区，加 +/- 微调按钮

### P2-3：帮助与反馈 段落"页面挂失"概念模糊
- 字号偏小 + 偏文案堆
- 修复：合并为 FAQ 折叠

### P2-4：Development chip 重复
- 头像区有 "Development" chip
- 右上 user card 也有 "Development"
- 修复：去重

## 视觉层级评估

- **视线流**：H1 → 用户卡 → 4 metric → 系统设置 → 帮助反馈
- **CTA 强度**：编辑资料 / 1.0x / 通过邮箱重置密码 — 3 个并列，**无主次**
- 修复：编辑资料升一档为 primary button

## 一致性

- ✅ 与 /、/training 同样的 sidebar 风格
- ✅ 圆角 / 字体 / 配色延续
- ❌ 修改密码入口走 /forgot-password 是反模式（业内多用 /change-password）

---

## 总结

/profile 整体工整，**主要问题在 P1-1（评分无解释）和 P1-3（改密码走错流程）**。其他都是 P2 优化。
