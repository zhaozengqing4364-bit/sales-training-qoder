## P0（必须修）

### P0-1：3 区块视觉权重等同
- **位置**：任务简报 / 评分标准 / 选择音频文件
- **现象**：
  - 3 区块用相同白卡 + 相同 24px 圆角 + 相同 H2 字号
  - 但实际重要性：**任务简报**是用户最关心的（要看清任务）→ **评分标准**是参考 → **上传**是操作
- **影响**：用户先看到空任务简报卡 vs 评分标准 vs 上传区，**视线不知道先去哪**
- **截图**：`sales-trainer-audio-default-1440.png`
- **修复方向**：
  - **任务简报升为 hero card**（高亮背景 / 边框 / 顶部主视觉）
  - 上传区保留为底部"操作卡"，加主 CTA 视觉
  - 评分标准折叠 / 收起到 ⓘ 链接

---

## P1（1 周内）

### P1-1：评分标准"70 分通过"无满分 / 无等级
- **位置**：评分标准 section
- **现象**：仅"70 分通过"，无 100 分制说明、无等级梯度
- **影响**：用户不知道 70 分算什么
- **修复方向**：用 metric 显示（当前空 / 目标 70 / 满分 100 / 优秀 ≥85）

### P1-2：文件大小限制在描述中，无前端校验
- **位置**：选择音频文件
- **现象**：描述写"不符合后端配置"但**没有具体大小数字**
- **影响**：用户上传 500MB 视频才被拒，体验差
- **修复方向**：
  - 描述明示 "建议 ≤ 50MB"
  - 前端 pre-upload size check，超限即时提示

### P1-3：上传 button "上传并开始评分" 默认 disabled
- **位置**：选择音频文件底部
- **现象**：选择文件前 button 灰
- **影响**：用户不知道下一步要做什么（"先选文件" 引导弱）
- **修复方向**：button 文案改 "选择文件以上传" / 旁边加 file input

## P2（可优化）

### P2-1：3 section 无图标区分
- 视觉上是 3 个相同白卡
- 修复：每个 section 加 icon（任务/规则/操作）

### P2-2：描述"上传主胶片讲解录音，由 AI 转写并评分（你将到 PPT 演练场）" 语义散
- 修复：分两行 + 强调动作"开始录音 → 上传"

### P2-3：评分通过 70 / 可多次上传 描述模糊
- 修复：补"未达 70 可重传"明示

## P3（可选）

### P3-1：无录音工具集成
- 用户需要去 /test-mic 测试麦克风，**本页不提供录音**

### P3-2：无样例音频
- 用户不知道"标准"长什么样
