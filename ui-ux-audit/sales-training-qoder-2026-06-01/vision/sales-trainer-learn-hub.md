# /sales-trainer/learn/hub 视觉分析

**wave**: dashboard | **截图数**: 1
**截图清单**：
- `screenshots/dashboard/sales-trainer-learn-hub-1440.png` — 拜访前商务（10 章）

**a11y 树要点**：
- 1 H1: "拜访前商务"
- 10+ chapter cards
- 0 console error
- sidebar "销售训练" active

---

## P0（必须修）

### P0-1：无阅读进度
- **位置**：10+ 章节卡
- **现象**：每张卡 "阅读本章" link 视觉权重完全等同，**用户不知道哪些已读、哪些未读**
- **影响**：
  - 用户每次进页都从头开始翻
  - 无法量化学习进度
  - 与 /learning-path 主页的"今日复练任务"脱节
- **截图**：`sales-trainer-learn-hub-1440.png`
- **修复方向**：
  - 已读章节：绿色 ✓ 标记 / link 变绿
  - 未读：保留当前视觉
  - 顶部加进度条 "3 / 10 已读 30%"

### P0-2：描述说"每章可配合测验"但页面无任何测验标识
- **位置**：H1 下方描述
- **现象**：写"每章可配合测验（若已发布）"但**没有任何卡显示"含测验" 标签**
- **影响**：用户不知道哪些章有测验
- **修复方向**：
  - 卡上标 `测验: 5 题` 徽章
  - 或在"阅读本章"旁加"📝 测验" button

---

## P1（1 周内）

### P1-1：章节名疑似机翻 / 生造词
- **位置**：10 个章节标题
- **现象**：
  - "指环木成洞验"
  - "科马洛米首查询验"
  - "异价值设计测验"
  - "渠道协作测验"
  - "首位技术交流测验"
- **影响**：用户根本不知道这些章节讲什么
- **修复方向**：核对原文 / 原文+解释

### P1-2：无章节时长 / 字数
- 用户无法估算学习时间
- 修复：每卡加"5 分钟" / "10 页" 标识

### P1-3：10 章全在一页
- 内容多时无折叠 / 无分页
- 修复：滚动加载 / 折叠"已完成"

## P2（可优化）

### P2-1：2 列 grid 偏密
- 1440 桌面下两列卡略挤
- 修复：lg 3 列 / xl 4 列

### P2-2：无搜索
- 章节多时无法搜索
