# 新人训练体验闭环设计

> **状态：Superseded / Legacy 历史记录（2026-07-16）。** 本文保留历史闭环方案，不再授权 Phase/Module、六类活动或 Realtime 首发；Foundation target 见 [`../../newcomer-foundation-contract-index.md`](../../newcomer-foundation-contract-index.md)。

## 目标

保留 `TrainingPath → Phase → Module → Activity` 活动编排模型，通过完善学员执行面、管理控制面和运营工作台，使新人训练达到“内容可配置、活动可扩展、操作不离开当前流程、发布可追踪且不会静默覆盖”的状态。

## 设计原则

1. 产品名称、PPT、Demo、技术学习主题都是配置数据，不进入路由、枚举或服务分支。
2. 新内容、新模块和六种既有活动不需要改代码；只有新增执行能力才扩展活动注册表。
3. 学员始终看到一个明确的下一步；完成活动后在当前页面得到结果和后续动作。
4. 管理员可以搜索既有资源，也可以在当前编辑流程中创建最小完整资源并自动绑定。
5. 草稿、检查、发布和恢复都基于明确修订号；并发冲突必须显式失败。
6. 路径编辑和学员运营是两个意图，使用独立页面，避免形成管理端 God Page。

## 学员端

### 训练首页

- 只有一个主操作，动作文案由活动类型决定，例如“开始录音讲解”“开始答题”。
- 只有承载主操作的阶段显示“当前主线”；其他未锁定阶段显示“可学习”。
- 首页与模块页显示预计用时；该字段从路径修订投影到 Journey DTO。
- 默认只展开当前主线阶段，其他阶段由学员主动展开。

### 活动执行

- `ActivityShell` 统一展示状态、预计用时、得分/通过状态以及完成后的下一步。
- 录音讲解支持浏览器录音、计时、停止、试听、重录和本地文件兜底。
- 有讲解材料时，学员可在当前页打开已发布版本，再确认本次使用版本。
- 上传后显示处理中、失败可重试、完成结果；不要求用户手工返回模块寻找下一步。

## 管理端路径编排

### 编辑器

- 大纲支持阶段/模块折叠、名称搜索和“只看问题项”。
- 保留拖拽，同时保留键盘可用的上下移动；操作目标不小于 40px。
- 模块编辑器暴露适用部门/角色/等级、前置模块和完成策略。
- 活动编辑器暴露前置活动和预计用时。
- 页面离开前提示未保存修改；保存成功后更新当前工作修订号。

### 资源选择与原地创建

- 资源选择支持搜索，显示资源状态，不再使用不可检索的长下拉列表。
- 快速建课必须填写真实章节内容；不再发布占位正文。
- 快速组卷必须由管理员明确选择题目；不再自动取题库前十项。
- 快速评分标准必须明确通过分和至少一个评分维度。
- 创建、发布、绑定是一个可见流程，失败留在当前弹窗并保留输入。

### 检查、发布和历史

- 检查候选路径不再隐式保存草稿。
- 保存草稿携带 `expected_revision_id`，服务端比较当前工作/活动修订，冲突返回 409。
- 发布接口接收候选 payload、修改说明和期望修订号，在单事务内校验、创建修订并发布。
- 发布前确认明确说明：既有学员继续使用已固定版本，新报名学员使用新版本。
- 管理端提供修订历史、修改说明和“恢复为草稿”。

### 资源加载韧性

- 路径主体优先加载。
- 七类资源目录使用独立结果；单个目录失败只禁用对应选择器，并提供重试，不阻断路径编辑。

## 运营工作台

- 新增 `/admin/newcomer-training/learners` 学员进度列表，支持部门筛选、分页、完成率和当前任务。
- 新增 `/admin/newcomer-training/learners/[learnerId]` 详情，展示阶段、模块、活动状态，并链接现有训练记录、录音管理和达标验收。
- 页面只消费现有 Journey/Readiness 权威接口，不复制评分或达标规则。

## 数据流

```text
TrainingPath revision
  → JourneyService projection
  → Journey DTO（含 estimated_minutes / primary action）
  → ViewModel（动作文案、阶段语义）
  → 学员页面

Path editor candidate
  → candidate validation（无写入）
  → atomic publish（expected revision + permission + audit）
  → immutable active revision
  → 新 enrollment 固定到新修订
```

## 错误与降级

- 麦克风不可用：显示原因并保留“上传已有录音”兜底。
- 材料预览失败：允许新窗口打开或下载，不伪造已查看状态。
- 资源目录失败：局部错误、局部重试，路径主体仍可编辑。
- 修订冲突：保留本地候选内容，提示重新加载并对比，不自动覆盖。
- 发布校验失败：问题可点击并聚焦到对应阶段、模块或活动。

## 测试

- 后端：候选校验无写入、并发草稿冲突、原子发布、预计用时投影、历史恢复。
- 前端：动作文案、唯一当前阶段、浏览器录音状态机、材料预览、完成后下一步、局部资源失败、大纲搜索折叠、并发冲突、历史恢复、运营列表与详情。
- 端到端：学员首页→录音活动、管理员编辑→检查→发布确认、学员运营列表→详情。

## 非目标

- 不新增第七种活动类型。
- 不把异步录音评分改造成实时对练；实时对练继续由既有 runtime 管理。
- 不重写全站设计系统，也不迁移全站状态管理框架。
