# Implementation Notes

## Plan

1. 以失败测试固定停用语义、对象级加载、超时恢复和管理员保护。
2. 后端集中账号状态变更规则，DELETE 保留为兼容停用入口。
3. 前端移除物理删除表述，关闭外层管理弹窗后再确认状态变更。
4. 验证真实渲染、慢响应、重复点击、权限与审计。

## Deviations

- 保留旧 `DELETE /admin/users/{id}` 作为向后兼容入口，但明确返回 `deleted=false`，并复用停用事务、管理员保护与审计；新页面不再调用该入口。
- 临时密码重置纳入同一套审计原因、凭证版本冲突和有界超时恢复，避免相邻账号治理写入继续保留相同风险。
- 全量质量门禁暴露出 OpenAPI 快照、模型/类型导入基线与新增实时对练绑定快照的依赖边界漂移；已同步生成契约和可解释基线，并把跨域读取收口到既有 `curriculum_practice_adapter` 适配层。
- 密钥卫生门禁发现历史 Playwright trace/report 压缩包包含会话令牌；已清理本机旧证据、让扫描器检查 ZIP 成员，并将 Playwright trace 改为显式启用，避免同类产物默认生成。
- 部署后 smoke 复现出 Tailwind v4 自动扫描 `web/.next-rollback-*` 生成物并把二进制片段误识别为 class，导致开发模式 CSS 解析 500；已将 Tailwind 扫描根限定为 `web/src`，同时让 smoke 使用独立 `.next-smoke` 目录，彻底隔离生产/测试缓存。

## Safety

- 不对当前数据库中的账号执行状态写入。
- 所有写路径验证使用隔离测试数据库或前端 mock。
- 线上只执行只读账号/团队核验；未创建、停用、启用、重置或删除真实账号。
