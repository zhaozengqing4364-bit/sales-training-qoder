# 组长只读数据与洞察

## Goal

构建按显式团队范围查询的销售组长只读进度、管理员已分配任务和可解释团队洞察 API。

## Scope

* 全部授权团队汇总及单团队筛选，按 learner_id 去重。
* 新人训练路径和额外训练任务两个独立聚合对象。
* 7/30/90 天、自定义区间及上一同长度周期对比。
* 基于截止时间、未推进必修项和发布通过标准的确定性风险分组。
* 成员详情统一时间线，保留数据来源和原始状态。
* 平台管理员任务分配结果可见；组长任务写接口一律 403。
* 不返回 readiness、calibration、retraining 数据。

## Acceptance Criteria

* [x] 团队、时间和成员过滤全部下推数据库，无全量加载后内存筛选。
* [x] 跨团队直接访问、缓存泄露和撤权后旧数据均被阻断。
* [x] 两套进度分母清晰且不生成综合百分比。
* [x] 周期边界、无基线、同一成员多风险和发布标准变化测试通过。
* [x] API 不提供个人排名及本期外主管写能力。
